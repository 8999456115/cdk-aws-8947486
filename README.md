## 🚀 How It Works

This project:
1. Uses **GitHub** as the source repository.
2. Runs **AWS CodeBuild** to:
   - Install CDK and dependencies
   - Run `cdk synth` to generate CloudFormation templates
3. Deploys via **AWS CloudFormation** using a stack generated by CDK.

---

## 🔧 Prerequisites

- AWS Account with:
  - S3
  - CodeBuild
  - CodePipeline
  - IAM permissions
- GitHub Repository connected to AWS CodePipeline
- CDK Installed:
  ```bash
  npm install -g aws-cdk
  ```

## 🛠 Setup Instructions

1. **Clone Repository**  
   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
   cd cdk-aws-8947486/cdk-app-8947486
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Deploy Stack Manually (Optional)**
   ```bash
   cdk bootstrap
   cdk deploy
   ```

4. **Configure AWS CodePipeline**
   - Connect to your GitHub repo.
   - Set source provider: GitHub.
   - Build provider: AWS CodeBuild.
   - Deploy provider: AWS CloudFormation.
